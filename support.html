Support

Last Updated: August 28, 2026

QUICKLOG is a free iPad flight-log and briefing notepad. This page is the support address for the Home Screen web app and the native iPad app.

A longer help / how-to section can be added on this same GitHub Pages site later. It does not need a second website.

Open the app

  • Web app (add to Home Screen on iPad): https://burbank.github.io/navlog-note/
  • Privacy policy: Purpose and Privacy Policy

Common notes

  • Log lines and form values stay on the device. Deleting the Home Screen web app or uninstalling the iPad app clears them.
  • Back up marked log lines with COPY MARKED AS TABLE or CSV before you clear the logbook.
  • The web app needs an online open once to cache. After that it is meant to work in airplane mode.
  • Crew-rest wake-up alerts on the web app only fire while QUICKLOG stays open. The native iPad app can use a system notification at rest end.
